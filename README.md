A two-part micro-confession for Unsent: The Micro-Confession Sprint — a
To: line and the one line that was typed and never sent. The addressee is
load-bearing: only Dad's saved voicemails still carry his voice saying the
sender's name, and the reason it stayed in drafts is felt, not stated —
too late to send, too honest to delete.

## Run it

```sh
node main.ts
```

Writes the confession to `/output/entry.txt` (93 characters, UTF-8).
